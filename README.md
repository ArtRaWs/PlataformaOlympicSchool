# PlataformaOlympicSchool
Olympic School

Olympic School é uma plataforma educacional voltada para professores e estudantes, com foco na preparação para olimpíadas científicas e linguísticas, oferecendo dashboards de acompanhamento, conteúdos organizados e assistente de IA integrado.

Projeto online:
https://artraws.github.io/PlataformaOlympicSchool/

 Objetivo:
 Auxiliar alunos no ingresso e preparo para olimpíadas do conhecimento, enquanto oferece aos professores ferramentas de gestão, acompanhamento de desempenho e organização de conteúdo.

 Funcionalidades:

Design interativo e intuitivo
